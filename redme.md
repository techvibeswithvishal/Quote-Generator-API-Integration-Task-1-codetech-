## 📘 Project Overview
This project is developed as **Task 1** of the **CODTECH Full Stack Development Internship**.

The goal of this task is to **create a responsive webpage that fetches and displays data from a public API** dynamically using JavaScript.  
This project demonstrates skills in API integration, asynchronous programming, and DOM manipulation.

---

## 🧩 Features
- Fetches **random quotes** from a public API.
- Displays the quote and author dynamically on the webpage.
- Includes a **"New Quote"** button to load fresh data each time.
- Handles API errors gracefully with a fallback message.
- Designed with **responsive layout** using CSS.

---

## 🛠️ Technologies Used
- **HTML5** – Structure of the webpage  
- **CSS3** – Styling and responsive design  
- **JavaScript (ES6)** – API fetching and dynamic content update  
- **Public API:** [Quotable API](https://api.quotable.io/random)
